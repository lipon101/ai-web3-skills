# Audit Report Examples (reference)

A small local corpus of real published audit reports, used as templates and calibration when drafting findings or full reports.

## Local copy

`documents/personal-ZUp1aMpW/audit-references/solodit-reports/`

Currently includes:
- `2026-05-12-cyfrin-molecule-onchainlab-v2.0.md` — Cyfrin audit of Molecule OnchainLab v2.0 (sourced from solodit_content). Use it as a reference for: finding layout (title / severity / description / impact / PoC / recommendation), severity rationale, and summary tables.

## How to use

1. When writing a finding or report, open a relevant example and mirror its structure and tone.
2. Pair with `gdocs-audit-report` (formatting in Google Docs) and `solodit` (searching for prior art across many more reports online).
3. To grow this corpus, download additional reports from the solodit_content repo into the same folder.

Reference material only — not an executable tool.
