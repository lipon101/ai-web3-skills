## How to use

1. Identify the target's protocol type / standards in scope.
2. Open `reference/README.md`, jump to the matching section, and pull the relevant external checklists.
3. Treat checklists as a coverage backstop, not a substitute for understanding the system — adapt each item to the actual code. Pair with `solcurity`, `auditmos-skills/*`, and the Plamen chain skills.
